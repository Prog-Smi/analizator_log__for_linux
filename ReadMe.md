# КАК ЗАГРУЗИТЬ СВОЙ ЛОГ?

1) загружаеш лог в папку с програмой 

2) переменовуеш свой лог на название 'log.txt'

3) запускаеш свою програму (ЧЕРЕЗ ТЕРМИНАЛ) 



# ОШИБКИ!!!

1) нельзя закидивать два log.txt

2) обязательно переминовуйте файл(лог) на 'log.txt'

3) не запускаете через терминал

4) не закинул 'log.txt'







# English/Англиский


# HOW TO UPLOAD YOUR OWN LOG?

1) Upload the log to the program folder 

2) Rename your log to 'log.txt'

3) Launch your program (THROUGH THE TERMINAL) 



# ERRORS!!!

1) You cannot put two log.txt files

2) You must rename the file (log) to 'log.txt'

3) Do not launch through the terminal

4) You did not add 'log.txt'
